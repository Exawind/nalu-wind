Detailed Description

template<typename BcAlgTraits>
class sierra::kynema_ugf::EnthalpyTGradBCElemKernel< BcAlgTraits >

Enforce a prescribed normal temperature gradient at the boundary.

This class handles both element and edge based BC implementation. To use this with edge-based schemes, pass useShifted = true.
