Detailed Description

Low-Mach formulation of the Navier-Stokes Equations.

This class is a thin-wrapper around sierra::kynema_ugf::ContinuityEquationSystem and sierra::kynema_ugf::MomentumEquationSystem that orchestrates the interactions between the velocity and the pressure Possion solves in the LowMachEquationSystem::solve_and_update method.
